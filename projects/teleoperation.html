Projects / Teleoperation

Internship, robotics startup, summer 2026

Force feedback for robot teleoperation

When a person controls a robot arm remotely, they can't feel what the gripper is touching. My summer work was about giving that sense of touch back to the operator, and getting control code to run reliably on real hardware.

In plain language Imagine steering a robot hand with a controller. Without force feedback, you can crush an object or drop it because you have no idea how hard you are squeezing. Force feedback pushes back on your hand so you can feel the grip.

The problem

Force sensors add cost, weight and wiring to a robot. I worked on estimating contact force from signals the robot already has, so the operator could get feedback without adding a dedicated sensor.

What I worked on

  • A force estimation system for teleoperation that needed no extra sensor.
  • Control code deployed into the robot's real-time control system.
  • Benchmarking vision-language-action (VLA) models on the team's tasks.

Why it matters to me

This was the first time my code had to work on a physical machine instead of a benchmark. Bugs showed up as a robot doing the wrong thing, which made testing and measurement feel very different from coursework.

The company is early stage, so I'm only sharing what I'm allowed to. I'll add a demo video and results here once they're cleared for public use.
